# BamScope Red Team

**Professional Red Team Network Reconnaissance, Device Fingerprinting & Packet Analysis Platform**

BamScope Red Team is a modular, extensible cybersecurity intelligence application designed for authorized network assessments, personal laboratories, education, and professional portfolio work.

## Current Status

**Phase 2 – Project Foundation** (in progress)

- [x] Development environment configured
- [x] Virtual environment created
- [x] Core dependencies installed
- [x] Project structure created
- [ ] Application shell (GUI)
- [ ] Network discovery engine
- [ ] Device fingerprinting
- [ ] Packet capture & analysis

## Technology Stack

- **Language**: Python 3.14
- **GUI**: PySide6 (Qt 6)
- **Packet Capture**: Scapy
- **Network Discovery**: python-nmap + custom engines
- **Database**: SQLAlchemy + SQLite
- **OS**: Kali Linux

## Important

This tool is intended **only** for networks and systems you own or have explicit written authorization to assess. Unauthorized scanning is illegal.
